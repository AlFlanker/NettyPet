# Нагрузочные сценарии

- [`get/`](get/) — GET больших HTML-ответов и существующий JMeter-план.
  Для ответа около 8 МиБ запускайте `python3 stress/get/server.py --size-mb 8`.
  Без флага сервер генерирует 1 МиБ. В приложенном JMX фактически заданы 20 потоков
  и лимит 300 rps (`18000` запросов/мин), несмотря на `500 rps` в имени и комментариях.
- [`docker/`](docker/README.md) — изолированный стенд: прокси 3 CPU / 4 ГиБ, приёмник 4 CPU / 4 ГиБ; метрики в уже запущенных Prometheus и Grafana.
- [`multipart/`](multipart/README.md) — multipart POST/PUT, бинарный файл 8 МиБ,
  текстовые поля, upstream с проверкой SHA-256 всего тела и каждой части,
  позитивный/негативный smoke-тест и параметризованный JMeter-план.
- [`cache/`](cache/README.md) — длительный HTTP-прогон кэша: hit/miss, вытеснение,
  медленные читатели и отключения, SHA-256 ответов 8 МиБ, измерения heap и GC.
