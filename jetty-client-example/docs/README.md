# Сборка PDF-гайда

`build_guide.py` — совместимый wrapper над общим [сборщиком](../../docs/pdf_guide.py).
Тот же код собирает [гайд Jetty + Netty](../../docs/jetty-netty/README.md).

Исходник — `guide.md`. Ровно 15 разделов отделяются отдельной строкой
`<!-- pagebreak -->`; каждый раздел начинается с `## Заголовок`. Один раздел
соответствует одному портретному листу A4. `guide.css` задаёт основной текст 10.5pt,
код и таблицы 9pt; высота header/footer — по 7.5mm, центральная область — 262mm
включая внутренние отступы. Диаграммы ограничены высотой 100mm.

Нужны Python 3.10+, локальные `pandoc`, `chromium`, `dot`, `pdfinfo`, `fc-match`
и шрифты **Noto Sans**, **Noto Sans Mono**, а также Python-пакет
**Playwright >= 1.42** в используемом Python-окружении.
В Debian программы и шрифты предоставляют пакеты `pandoc`, `chromium`,
`graphviz`, `poppler-utils`, `fontconfig`, `fonts-noto-core`, `fonts-noto-mono`.
Playwright запускает системный исполняемый файл `chromium` из `PATH`;
команда `playwright install` и загрузка браузеров Playwright не требуются.
Сама сборка не скачивает программы, шрифты, JavaScript или другие ассеты.

Текущий набор версий окружения:

| Инструмент | Версия |
| --- | --- |
| Pandoc | 3.1.11.1 |
| Chromium | 154.0.8037.57 |
| Graphviz | 2.42.4 |
| Python-пакет Playwright | 1.62.0 |

Для того же Python-пакета установите его в выбранное Python-окружение:

```bash
python3 -m pip install 'playwright==1.62.0'
```

Из корня репозитория:

```bash
python3 jetty-client-example/docs/build_guide.py --check
python3 jetty-client-example/docs/build_guide.py
```

Проверка и сборка также работают из другого рабочего каталога: все пути
определяются относительно самого скрипта. Итоговый файл —
`jetty-client-example/docs/jetty-client-guide.pdf`.

Скрипт сначала переводит каждый раздел отдельно через Pandoc в HTML и собирает
все разделы в фиксированные A4-листы. Через Playwright
`launch_persistent_context()` запускается системный Chromium в headless-режиме
с `--no-sandbox`. `page.emulate_media(media="print")` включает режим печати,
а `page.set_content()` передаёт HTML браузеру.
JavaScript-проверка выполняется после загрузки шрифтов и изображений: переполнение
по обеим осям, выход элементов за область текста/header/footer, пропавшие
изображения, дубли ID и несуществующие внутренние anchors завершают сборку
с ненулевым кодом. Допуск геометрии 0.5 CSS px учитывает дробное округление.
Текст не уменьшается автоматически, содержимое не обрезается.

`--check` выполняет эту проверку без замены итогового PDF. Обычная сборка
выполняет ту же проверку, печатает PDF через Chromium без встроенных browser
header/footer вызовом Playwright `page.pdf(tagged=True, outline=True)`, затем
проверяет через `pdfinfo`, что получилось ровно 15 страниц.
Старый итоговый PDF заменяется только после успешного завершения всех проверок.

Все `diagrams/*.dot` при каждом запуске, включая `--check`, преобразуются
локальным Graphviz в соседние `diagrams/*.svg`. В Markdown используйте пути
вида `diagrams/upload.svg`. Скрипт встраивает локальные изображения в HTML как
data URI с base64.
Удалённые и абсолютные URL изображений запрещены. HTML, промежуточный PDF и
профиль Chromium создаются во временном каталоге внутри `docs` и удаляются
после завершения, включая ошибку. Правки `.gitignore` не требуются.

Ссылки между листами записываются как `[Upload](#page-5)`. Явные anchors
`<a id="page-5"></a>` сохраняются; если их нет, builder добавляет anchor сам.
HTML-обёртки листов имеют отдельные IDs `sheet-N`; в PDF ссылки `#page-N`
направляются на начало соответствующего листа. Поддерживаются также
ссылки на уникальные ID заголовков и `guide.md#...`; IDs отдельных HTML-разделов
получают префиксы, поэтому одинаковые заголовки на разных страницах не создают
дубликаты. Для неоднозначной межстраничной ссылки используйте `#page-N` или
явный уникальный ID Pandoc: `### Пример {#unique-example}`.

Скрипт печатает общее число слов и число слов каждого Markdown-раздела,
включая код и разметку. Это служебный счётчик, а не критерий вместимости листа:
вместимость проверяется по фактической геометрии Chromium. Для сопоставимых
результатов используйте одинаковые версии Pandoc, Chromium, Graphviz, Playwright и Noto.
PDF может содержать текущую дату создания, поэтому побайтовая идентичность
файлов разных сборок не обещается.
